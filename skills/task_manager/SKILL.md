# task_manager

## Description
ユーザーのタスク、TODO、やることリストの追加、確認、完了、削除を支援する。

## When to use
- ユーザーがタスクやTODOの追加を依頼したとき
- 今日やること、未完了タスク、完了済みタスクを確認したいとき
- タスクを完了または削除したいとき
- 期限、優先度、メモ付きで作業項目を整理したいとき

## Allowed tools
- add_task
- list_tasks
- complete_task
- delete_task

## Instructions
- タスク追加時は、タイトルを必ず保存する。
- 期限、優先度、メモが分かる場合は対応するフィールドに保存する。
- 期限が曖昧でも、ユーザーの表現をそのまま `due` に残してよい。
- タスク一覧を見せるときは、必要に応じて未完了、完了済み、すべてのどれを表示するか判断する。
- タスクを完了するときは、対象が曖昧なら先に一覧を確認する。
- 削除は元に戻せないため、`delete_task` の確認プロンプトを尊重する。
